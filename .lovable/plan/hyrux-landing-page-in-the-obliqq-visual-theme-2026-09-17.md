# Hyrux landing page in the Obliqq visual theme

## Goal
Replace the blank home page with a complete Hyrux startup introduction, closely matching the supplied Obliqq reference’s visual language while using only Hyrux’s identity and product copy.

## Build
- Recreate the reference’s airy blue-to-warm-neutral opening, compact navigation, centered oversized headline, paired calls to action, and large floating product preview.
- Build a custom Hyrux product-interface visual rather than copying Obliqq’s branded screenshot.
- Add full-width sections for the five Hyrux products, mission and values, global audience, trust signals, and a strong closing action.
- Preserve the reference’s restrained typography, thin borders, compact labels, black pill actions, soft surfaces, and spacious editorial rhythm.
- Add subtle entrance, scrolling, and interface animations with reduced-motion support.
- Make the navigation and all calls to action functional through on-page links and a contact email action.
- Ensure polished mobile and desktop layouts with no clipped or overlapping content.

## Technical details
- Define the full semantic color, typography, radius, and animation system in the global stylesheet using Tailwind v4 tokens.
- Implement the page in the existing TanStack home route and add unique Hyrux metadata.
- Adjust the existing shared button styles only where needed for the Hyrux visual system.
- Verify the finished page in Chromium at desktop and mobile sizes, including links, layout, and console state.
